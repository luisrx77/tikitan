# tikitan

Proyecto de ejercicios de Python sobre funciones, módulos y programación orientada a objetos.

## Requisitos

- Python 3

## Instalación

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Archivos

- `calculadora.py`: operaciones aritméticas.
- `main.py`, `usuario.py` y `varios.py`: ejercicios y ejemplos de Python.
- `requirements.txt`: dependencias del proyecto.
